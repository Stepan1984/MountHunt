# Resort detail photos — sources

Exactly one optional hero photo per resort detail page. Images live in `public/photos/resorts/`. Metadata (`photo`) is on each resort in `data/seed/resorts.json` / `public/data/resorts.json`.

Policy:

- Use a real, clearly attributable licensed photo of **this** place.
- The photo must show **snowy / operating winter slopes** (ski runs, snow cover, and ideally lifts in winter). Summer/green views, lake-only scenery, indoor-only shots, and non-slope winter scenes are not used.
- If no such image is found, omit the photo (no stock stand-ins, no nearby-but-different slopes).
